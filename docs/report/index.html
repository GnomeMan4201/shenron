Read this before the numbers

  • The rule hit counts on the 50 demo events are solid. Two independent reviews reproduced them.
  • The scenario scores come from SHENRON's campaign brittleness scorer, and the reviews found four defects in it. The biggest: it checked every event in a stage before mutation but only the single mutated event after, so a rule still firing on a sibling event counted as evaded. Fixing that alone takes all six scenarios to 0.00. It also counted stages no rule detected as evasion, only mutated the layer field, and drew seeds that changed between runs. With all four fixed in PR #71, all six scenarios score 0.00 in three runs, so the scenario ranking is withdrawn.
  • The mutation rounds and per-rule scores come from a different code path, and they reproduce exactly with and without PR #71. They are accurate but narrow: the only detection field any round changed was layer. They show which rules depend on that one label, not how rules hold up against real attacker variation.
  • 0.00 isn't proof of durability either. The rules still match on labels the mutator never changes. PR #72 pilots rules that match on simulated observables instead.
