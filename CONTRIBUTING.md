# Contributing

## Ground rules
- Research-only usage; no requests for weaponization or illegal use.
- Keep modules modular and testable; add unit tests for new features.
- Write docs and examples for new components.

## Dev setup
- Python 3.11+ recommended.
- `pipx install pre-commit` (or `pip install pre-commit`)
- `pre-commit install`
- `make test` before pushing.

## Commit style
- Conventional Commits (feat:, fix:, docs:, chore:).
